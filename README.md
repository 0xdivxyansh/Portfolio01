## Getting Started

```bash
# Clone
git clone https://github.com/0xdivxyansh/Portfolio01.git
cd Portfolio01

# Install
npm install

# Development
npm run dev

# Type check
npm run typecheck

# Production build
npm run build

# Preview production build
npm run preview
```
